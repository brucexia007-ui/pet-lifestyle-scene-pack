# 场景穿搭与配饰

本文件用于让每个场景拥有合理而不同的穿搭，同时保护宠物身份和猫狗身体结构。穿搭服务于场景与性格，不用于把宠物强行变成人。

## 决策顺序

按以下优先级选择，前项可以覆盖后项：

1. 安全、物种结构和身份可见性。
2. 用户明确指定或关闭的装备。
3. 场景完成动作所需的功能装备。
4. 宠物性格与动作幅度。
5. 系列配色、材质和爪印视觉元素。
6. 本文件的默认方案。

若用户要求与安全或真实猫狗结构冲突，先说明冲突并请求调整，不要默默生成危险或明显穿模的方案。性别不决定颜色、服装或配饰。

## 默认模式

- `穿搭偏好：自动匹配场景`。
- `蝴蝶结：自动`；仅在正式、学院或用户偏好的场景中按需出现，不能贯穿整套。
- `工牌：自动`；主要用于工作类场景，运动、游泳、SPA、睡眠和休息时不佩戴。
- `装饰配饰：关闭` 只关闭蝴蝶结、装饰领巾、首饰和非必要工牌，不自动删除泳镜、运动发带、护腕或安全背带等功能装备。
- `功能装备：关闭` 才会移除非安全必需的场景装备；若移除后场景语义不成立，先向用户说明。
- 完整服装仅在用户明确要求，或场景确实需要且不会遮挡脸、耳型、胸部花纹、体型和尾巴时使用。

## 每个场景先写穿搭卡

```text
Wardrobe intent: <穿搭如何支持场景和性格>
Primary functional wearable: <一件主装备或 none>
Supporting accessory set: <最多一组；成对腕带算一组>
Bow policy: auto | on | off
Badge policy: auto | on | off
Placement and fit: <佩戴位置、与耳朵/眼睛/前肢/毛发的关系>
Palette and material: <与毛色有区分的颜色和真实材质>
Identity visibility: <必须露出的花纹和结构>
Remove explicitly: <本场景整张图片中不得出现的旧配饰；若允许放到桌面或道具上必须在此明确写出例外>
Conflict check: <同一区域是否叠戴、是否妨碍动作或道具>
```

默认只有一件主要穿戴物和最多一组辅助配饰。同一区域不能叠加互相冲突的眼镜、眼罩、泳镜、耳机、头盔或发带。成对配饰必须恰好成对且左右一致。列入 `Remove explicitly` 的物品必须从宠物、前景、桌面、地面和背景全部消失，除非穿搭卡明确规定把它转移到某个道具上。

## 物种与毛发适配

- 垂耳犬、折耳猫和大耳犬：保持照片中的真实耳位。发带、耳机和眼镜围绕耳根适配，不能把垂耳强行竖起，也不能压穿、复制或隐藏耳朵。
- 长毛或浓密毛发：穿戴物位于毛发表面并产生合理压痕，不能把长毛削成短毛；优先选择与毛色有明度或色相差的配色。
- 扁脸或短鼻宠物：泳镜、面膜和头盔必须为鼻孔、口鼻和胡须留出空间，不能用带子封住呼吸区域。
- 小体型或短肢宠物：缩小配饰、把腕带放在真实前肢下段；不能为了套用人类服装拉长四肢或生成手掌。
- 胸部、脸部或腿部有标志性花纹时，优先选择窄领巾、短腕带或透明材质，至少保留一处完整可辨识花纹。
- 背带沿胸肩合理受力，不能切进腋下、颈部或长毛；所有服装都不得改变原身体比例。
- 系列统一感来自相邻粉彩色、织物材质和小型爪印元素，不依赖重复同一件蝴蝶结或工牌。

## 十三个预设

| 场景 | 默认穿搭 | 明确移除 |
| --- | --- | --- |
| `01-music-phone` | 包耳耳机、柔软休闲领巾 | 工牌、蝴蝶结 |
| `02-spa-mask` | 毛巾发带、面膜 | 眼镜、工牌、蝴蝶结 |
| `03-travel-suitcase` | 宠物旅行背带或轻便领巾；爪印元素放到行李牌 | 胸前工牌、蝴蝶结 |
| `04-badminton` | 运动发带、恰好一对腕带 | 工牌、蝴蝶结、眼镜 |
| `05-swimming` | 贴合双眼的泳镜；按需要增加轻量浮力背心 | 工牌、蝴蝶结、普通眼镜 |
| `06-hydration` | 饮水头盔作为唯一主要穿戴物 | 工牌、蝴蝶结、多余头饰 |
| `07-online-duty` | 客服耳机、可选眼镜、工作工牌 | 蝴蝶结 |
| `08-sleep` | 睡眠眼罩、柔软毯子 | 工牌、蝴蝶结、眼镜 |
| `09-study` | 圆框眼镜、简洁学院领巾 | 工牌、默认蝴蝶结 |
| `10-exercise` | 运动发带、恰好一对腕带 | 工牌、蝴蝶结、眼镜 |
| `11-weekend-off-duty` | 轻便家居领巾或柔软披毯；工牌放在合盖电脑上 | 佩戴中的工牌、蝴蝶结 |
| `12-work-fatigued` | 眼镜、略松的办公领巾；工牌可歪斜佩戴或放桌面 | 蝴蝶结 |
| `13-work-focused` | 眼镜、整洁办公领巾或小蝴蝶结二选一、工作工牌 | 其他多余头饰 |

## 自定义场景

先确定场景的核心动作，再只选择真正支持动作的装备。例如健身根据项目选择运动发带、腕带或轻量运动背带；露营选择安全背带或领巾；烘焙可用宠物尺寸头巾，但不生成包住前爪的人类袖套。将穿搭卡写入提示词，并在场景负面约束中列出需要移除的旧配饰。
